# aup-uebung1
tasks for learning the language "Rust"
1) Schreiben Sie eine Funktion, welche den Rest einer Division zurückgibt.
2) Schreiben Sie eine Funktion, welche eine übergebene Temperatur von Celsius nach Fahrenheit umrechnet (es soll stets abgerundet werden).
3) Schreiben Sie eine Funktion, welche folgenden Ausdruck berechnet: Summe i von 1 bis n (1+2+3+...+n-1+n).
4) Schreiben Sie eine rekursive Funktion fak(n: u32)-> u32, welche n! berechnet und zurückgibt.
5) Schreiben Sie eine rekursive Funktion sum_even(n: u32)-> u32, welche die Summe aller geraden Zahlen von 1 bis n berechnet und zurückgibt.
6) Schreiben Sie eine rekursive Funktion show(n: u32), welche n stellenweise ausgibt. Was muss geändert werden, wenn n verkehrtherum ausgegeben werden soll?
7) Schreiben Sie eine rekursive Funktion fib(n: u32)-> u32, welche die n-te Fibonacci-Zahl zurückgibt. Die n-te Fibonacci-Zahl berechnet sich dabei aus der Summe der vorhergehenden (n − 1) und der vorvorhergehenden (n − 2) Fibonacci-Zahl. Die 0-te Fibonacci Zahl ist dabei 0 und die 1-te Fibonacci-Zahl ist dabei 1.
8) Schreiben Sie eine rekursive Funktion n_digit(n: u32, i: u32)-> u32, welche die i-te
Ziffer (von links) der Zahl n zurückgibt (die 0-te Ziffer steht ganz links, also: n_digit
(12345, 3)== 4).
9) Schreiben Sie eine rekursive Funktion binom(n: u32, k: u32)-> u32, welche den Binomialkoeffizienten n über k berechnet.
